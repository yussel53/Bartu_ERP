# Hazır aktarım paketleri

`FrontendUI/public/import-packs/` altında tutulur; Veri Aktarımı ekranında **Logo’dan aktar** / **Mikro’dan aktar** ile yüklenir.

Biçim, elle dışa aktarılan profil JSON’u ile aynıdır (`kind`, `source`, `map`, …).

SQL bağlantısı ekranda bir kez sorulur ve seçilen tüm paketlere yazılır.
