# KaviSoft tanıtım sitesi

Statik site (HTML + CSS, dış bağımlılık yok): `index.html`, `style.css`. Herhangi bir web barındırmaya (IIS, nginx, GitHub
Pages, Netlify…) klasör olarak kopyalanır. Açık / koyu tema tarayıcı ayarına göre.

**Yayımlamadan önce:** `index.html` içindeki «İLETİŞİM BİLGİLERİ» yorumunun altındaki e-posta ve telefonu gerçek bilgilerle
değiştirin (şu an yer tutucu: info@kavisoft.com.tr, +90 000…).

Yardım dokümanları bu sitede **yoktur**: program içinde, yalnız oturum açmış kullanıcıya gösterilir
(`BackendAPI/Help/*.md` → `api/help`).
